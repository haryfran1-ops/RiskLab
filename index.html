Cierre

Observar mejor amplía las preguntas que podemos hacer.

Un resultado agregado puede ocultar diferencias. Entre dos mediciones puede existir una trayectoria. Un mismo evento puede afectar de manera distinta a diferentes unidades de análisis. Simular permite explorar escenarios posibles para reflexionar sobre prevención.
